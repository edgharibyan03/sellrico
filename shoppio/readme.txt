AI assistant for WordPress and WooCommerce — connect your site to the Shoppio platform.

== Description ==

Shoppio connects your WordPress (and WooCommerce) site to the Shoppio SaaS backend.
This foundation release provides connection, authentication, and API client infrastructure.
AI chat, product sync, and the visitor widget are planned for future releases.

== Installation ==

1. Run `composer install` in the plugin directory.
2. Upload the `shoppio` folder to `/wp-content/plugins/`.
3. Activate the plugin through the Plugins menu.
4. Open Shoppio settings and connect to your Shoppio API.

== Frequently Asked Questions ==

= Does this include the AI chat widget? =

Not yet. This release is the connection foundation only.
